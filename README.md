## ⚡ Executive Overview

Modern high-performers, students, athletes, and engineers suffer from **subscription fatigue** and cognitive fragmentation across 7+ disconnected single-purpose apps:
- Workout loggers & 1RM calculators ($10/mo)
- Calorie counters & macronutrient trackers ($12/mo)
- Focus Pomodoro timers & ambient soundscapes ($5/mo)
- Spaced repetition flashcards & active recall utilities ($6/mo)
- Speech-to-text lecture transcribers ($8/mo)
- Expense managers & outing splitters ($5/mo)
- Password keepers & encrypted storage vaults ($4/mo)

**LifeOS** unifies your complete daily life management into a single, cohesive, offline-first operating system. Built with **React 18**, **TypeScript 5.5**, **Tailwind CSS**, and **Capacitor 8**, LifeOS runs seamlessly as both a blazing-fast responsive web application and a native hardware-accelerated Android app with local biometric authentication, 120 FPS animations, Google Sans Flex variable typography, and zero tracking or paywalls.

## 🌟 What's New in v3.2.3 (Build 61)

* **🧭 Path Memory Sequential Back Navigation**: The app memorizes your entire navigation journey step-by-step. Pressing hardware or gesture back smoothly retraces your exact path across all 30+ interfaces before triggering the double-tap exit guard.
* **✨ Universal Google Sans Flex Typography**: Integrated full-variable optical font sizing, enhanced heading letter depth (`-0.02em`), and unified typographic hierarchy across all pages.
* **📱 4-Column Squircle Navigation Hub**: Redesigned the floating bottom sheet with optimized tile geometry and multi-line label scaling, preventing any text clipping or page shifts behind device status bars.
* **🤖 Luna AI Autonomous Action Engine**: Enhanced speech-to-action parser that directly executes structured JSON actions (`ADD_TASK`, `LOG_EXPENSE`, `ADD_SHOPPING_ITEM`, `LOG_WORKOUT`) into your local storage.
* **🎯 Clean Flashcard Popups**: Replaced modal backdrops with clean transparent overlays for distraction-free flashcard creation.
* **📦 Autonomous In-App Sideload Updater**: Native OTA client that checks remote `version.json`, verifies SHA-256 cryptographic signatures, and triggers the Android `PackageInstaller`.

## 🚀 Quickstart & Development

### Prerequisites
* **Node.js**: `v18.0.0` or higher
* **npm**: `v9` or higher
* **JDK**: OpenJDK 17
* **Android Studio**: Ladybug (or newer) with Android SDK 34+

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/Avineesh-G/LIFEOS.git
cd LIFEOS/lifeos
npm install
```

### 2. Environment Setup (Optional for Cloud Sync)
Create a `.env` file in the `lifeos/` directory:
```env
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
VITE_FIREBASE_APP_ID=your_app_id
```

### 3. Launch Development Server
```bash
npm run dev
```
Open **`http://localhost:5173/`** to view the application.

## 📦 Build & Release Pipeline

```bash
# 1. Compile TypeScript & Vite production bundle
npm run build

# 2. Sync web build to native Android Capacitor project
npx cap sync android

# 3. Assemble signed release APK
cd android && .\gradlew.bat assembleRelease && cd ..

# 4. Compute SHA-256 checksums & update version manifests
node scripts/prepare-release.js
```
