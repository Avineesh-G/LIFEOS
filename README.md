## Executive Overview

Modern high-performers, engineers, students, and athletes suffer from severe cognitive fragmentation and subscription fatigue across multiple disconnected single-purpose tools:

* **Workout Loggers & 1RM Calculators** ($12/mo)
* **Calorie Counters & Macronutrient Trackers** ($14/mo)
* **Focus Pomodoro Timers & Ambient Noise Apps** ($6/mo)
* **Spaced Repetition Flashcards & Active Recall** ($7/mo)
* **Speech-to-Text Lecture & Meeting Transcribers** ($10/mo)
* **Daily Expense Managers & Trip Bill Splitters** ($8/mo)
* **Encrypted Password Keeps & Biometric Vaults** ($6/mo)

**LifeOS** unifies your entire daily workflow into a single, cohesive, offline-first operating system. Built with **React 18**, **TypeScript 5.5**, **Tailwind CSS**, and **Capacitor 8**, LifeOS operates as both an ultra-fast web application and a native hardware-accelerated Android APK with local biometric authentication, **Apple Dark Glass & Water Droplet** elevation, True OLED Pure Black surfaces, 120 FPS animations, Inter Variable typography, and **zero tracking, telemetry, or paywalls**.

## Core High-Performance Workflows

LifeOS is architected around how high-performers, engineers, and students actually navigate their daily routine. Below are the 8 fundamental workflows engineered into the system:

```mermaid
graph TD
    A[Morning Battle Plan Briefing] --> B[College Timetable & Lecture Alarms]
    B --> C[Deep Work Pomodoro / Flow Room]
    C --> D[Active Recall Flashcard Decks]
    D --> E[Campus Mess Meal & Macro Logging]
    E --> F[Hypertrophy Gym Session & Rest Timer]
    F --> G[Daily Expense & Outing Settlement]
    G --> H[Biometric Vault & Night Sync]
```

### Workflow 1: Circadian Day Rhythm & Morning Briefing
1. **Circadian Detection**: LifeOS automatically adapts UI surfaces across Dawn, Morning, Afternoon, Dusk, Evening, and Night.
2. **Morning Briefing Synthesis**: 1-Tap opening of the **Morning Battle Plan**, synthesizing today's academic timetable, scheduled workout split, urgent task deadlines, and daily motivation marquee ticker.
3. **Habit Dot Checkpoint**: Interactive habit dot indicators allow instant completion check-offs directly on the home interface.

### Workflow 2: Hypertrophy Training & Progressive Overload
1. **Split Selection**: Open Gym to automatically view the day's scheduled split (Push / Pull / Legs, Upper / Lower, or Custom).
2. **High-Speed Set Logging**: Enter weights, reps, and RPE. Previous session PR hints are displayed right above each input.
3. **Automated Floating Rest Timer**: Tapping set completion triggers an automated floating rest countdown with subtle haptic vibration cues.
4. **1RM Analytics**: The engine computes 1RM estimations via the Brzycki formula and plots historical progression curves.

### Workflow 3: Campus Mess & Daily Nutrition Tracking
1. **Macro Ring Status**: Review dynamic circular progress rings for Protein, Carbohydrates, Healthy Fats, and Calories.
2. **Mess Menu Integration**: Pre-configured campus mess schedules instantly show what is being served for Breakfast, Lunch, Snacks, Dinner, and Night Canteen.
3. **Water Intake HUD**: Log hydration with quick increments (+250ml / +500ml) to hit daily hydration goals.

### Workflow 4: Deep Work Flow Room & Spaced Repetition Recall
1. **Flow Room Activation**: Launch a distraction-free Pomodoro session with subject tagging.
2. **Zero-Download Ambient Soundscapes**: Synthesizes client-side Web Audio soundscapes including **Binaural Beats (Alpha 10Hz / Beta 20Hz)**, **Pure Brown Noise**, and **Rain**.
3. **Active Recall Decks**: Flip through spaced repetition flashcard decks with self-rating retention algorithms (Again, Hard, Good, Easy) for 2x knowledge retention.
4. **Annual Consistency Grid**: Sessions automatically contribute to your 365-day GitHub-style discipline heatmap.

### Workflow 5: Outing Trips & Group Expense Settlement
1. **Trip Itinerary & Packing**: Build multi-day timelines, location spots, and essential luggage checklists.
2. **Shared Expense Logging**: Add group outing expenses (cafes, transit, admissions) with flexible split configurations.
3. **Net Debt Settlement Matrix**: The algorithm calculates exact net balances (who owes whom the minimum number of transactions).
4. **1-Tap Clipboard Text**: Generate a formatted WhatsApp / Telegram payment summary with a single tap.

### Workflow 6: Luna AI Autonomous Execution (Speech-to-Action)
1. **Natural Command**: Speak or type actions naturally (for example, *"Log 4 sets of Bench Press at 85kg for 8 reps"* or *"Paid 1200 for groceries"*).
2. **Autonomous Parser**: Luna converts natural language into structured JSON payloads (`LOG_WORKOUT`, `LOG_EXPENSE`, `ADD_TASK`, `ADD_SHOPPING_ITEM`).
3. **Action Confirmation Card**: Review parsed data on a sleek confirmation card before committing.
4. **Local DB Mutation**: Commits directly to local offline IndexedDB with 0ms server latency.

### Workflow 7: Biometric Hardware Security & Vault Encryption
1. **Hardware Authentication**: Secure biometric challenge via AndroidX `BiometricPrompt` (Fingerprint / Face ID) with PIN fallback.
2. **Client-Side Cryptography**: AES-256-GCM symmetric encryption with PBKDF2 key derivation for confidential credentials and private notes.
3. **Auto-Lock Guard**: Automatically locks down the vault whenever the application is sent to the background.

### Workflow 8: Sideload & In-App OTA Auto-Updating
1. **Automated Manifest Check**: The app periodically polls `version.json` in the background for new releases.
2. **Cryptographic Verification**: Computes and matches SHA-256 checksums before installation.
3. **1-Tap In-Place Install**: Dispatches the Android `PackageInstaller` to update the native APK seamlessly without Play Store dependencies.

## 3-Tier Adaptive Device Rendering Rules

To ensure 100% jank-free performance and 120 FPS motion across all physical Android hardware without draining battery or causing GPU layer thrashing, LifeOS employs a 3-tier hardware-adaptive rendering system:

| Tier | Target Devices | Visual Pipeline | Frame Budget |
|---|---|---|:---:|
| **Tier 1 (Flagship)** | Snapdragon 8 Gen 2+, Tensor G3, Dimensity 9200+ | Full-fidelity liquid glass droplets with 10px-16px multi-pass blur and saturated specular rims | Locked 120 FPS |
| **Tier 2 (Balanced)** | Mid-range devices (Snapdragon 7/6 series, Dimensity 7000) | Single-pass 4px blur with optimized layer composition | 90 - 120 FPS |
| **Tier 3 (Budget / Battery Saver)** | Low-RAM devices or Battery Saver mode active | Zero GPU blur overhead (`backdrop-filter: none`). Solid `#18181B` high-contrast cards | Locked 60 / 120 FPS |

## Quickstart & Development

### Prerequisites
* **Node.js**: `v18.0.0` or higher
* **npm**: `v9` or higher
* **JDK**: OpenJDK 17
* **Android Studio**: Ladybug (or newer) with Android SDK 34+

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/Avineesh-G/LIFEOS.git
cd LIFEOS/lifeos
npm install
```

### 2. Environment Setup (Optional for Cloud Sync)
Create a `.env` file in the project root:
```env
VITE_FIREBASE_API_KEY=your_firebase_api_key_here
VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your_project_id_here
VITE_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id_here
VITE_FIREBASE_APP_ID=your_app_id_here
```

### 3. Launch Development Server
```bash
npm run dev
```
Open **`http://localhost:5173/`** to view the application or **`http://localhost:5173/download`** to view the Showcase & Download website.

## Build & Release Pipeline

```bash
# 1. Compile TypeScript & Vite production bundle
npm run build

# 2. Sync web build to native Android Capacitor project
npx cap sync android

# 3. Assemble signed release APK
cd android && .\gradlew.bat assembleRelease && cd ..

# 4. Compute SHA-256 checksums & update version manifests
node scripts/prepare-release.js
```
